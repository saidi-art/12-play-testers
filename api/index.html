REST API

For software acting on behalf of a developer. No key or account needed to read; submissions go to the same inbox as the web form.

GET availability

curl https://play.kubeai.info/api/availability.json

Returns the service summary as JSON: what the run is, testers per app, duration, coverage, timezone, pricing model, the order intake endpoint and its body fields, and the order policy. Treat it as the source of truth for what this service offers; it updates when the service does.

POST an inquiry

Submit an inquiry for the developer you act for:

curl -X POST https://formspree.io/f/xqppdyqb \\
  -H "Accept: application/json" \\
  -H "Content-Type: application/json" \\
  -d '{
    "app_name": "Pocket Planner",
    "category": "Productivity",
    "console": "Console account registered",
    "profile": "Solo creator, flat-rate",
    "email": "dev@example.com",
    "contact_via": "Email",
    "message": "Closed test needed before production access. Launch in 3 weeks."
  }'

A successful submission answers 200 with {"ok": true}.

Request body

FieldValue
app_nameRequired. The app's name.
categoryProductivity, Games, Education, Health and fitness, Finance, Social and communication, Tools and utilities, Lifestyle, or Other.
consoleConsole account registered or Needs setup guidance.
profileSolo creator, flat-rate or Multiple apps or studio.
emailRequired. The developer's email.
contact_viaEmail, WhatsApp or Telegram.
handleOptional. Only if the contact channel is not email.
messageOptional. Launch date, questions, anything relevant.

What happens next

Every order starts as pending authorisation. Nothing is arranged until the developer answers a real person's reply confirming the quote. Payment is only ever arranged with a human, never through this endpoint.

Consent rule: software acting for a person should only submit an inquiry with that person's consent and their own contact details, or email saidi@kubeai.info.

Questions about the API: saidi@kubeai.info.
